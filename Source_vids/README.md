# Local video inputs

Place `north.mp4`, `east.mp4`, `south.mp4` and `west.mp4` here. Use your own recordings or footage whose license permits your intended use. All four files must be readable by OpenCV. Direction names are input labels, not automatic geographic inference.

The original local files (approximately 4.8, 6.5, 4.5 and 3.7 MB respectively) remain on the developer machine and are ignored by Git because no redistribution license or provenance was supplied. No third-party sample download is implied.
